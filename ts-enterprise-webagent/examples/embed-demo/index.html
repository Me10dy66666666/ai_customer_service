WebAgent Widget 嵌入示例

将 <web-agent-widget> 嵌入任意页面，一行代码即可获得智能客服能力。

嵌入方式

方式一：HTML 标签属性

<web-agent-widget
  api-endpoint="http://localhost:3400/api/v1/agent/customerService"
  theme-color="#4c6ef5"
  user-type="1"
  placeholder="请输入您的问题…"
  welcome-message="您好！我是智能客服助手，有什么可以帮您？"
  history-orders="2025年购买过无线耳机"
></web-agent-widget>

方式二：JavaScript API

const widget = document.getElementById('my-widget');
widget.updateConfig({
  apiEndpoint: 'http://localhost:3400/api/v1/agent/customerService',
  userType: 1,
  themeColor: '#4c6ef5',
  welcomeMessage: '您好！我是智能客服助手。',
});
